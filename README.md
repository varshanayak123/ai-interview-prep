# AI Interview Prep

An AI-powered Interview Preparation Platform designed to help students, freshers, and job seekers improve their technical interview skills.

## 🚀 About the Project

AI Interview Prep helps users practice programming interview questions, test their technical knowledge, and receive AI-powered feedback on their answers.

Users can prepare at their own pace through different interview rounds and track their progress over time.

## ✨ Features

- User Authentication (Sign Up / Login)
- Multiple Programming Languages
- Three Levels of Interview Rounds
- Technical Interview Questions
- AI-Powered Answer Evaluation
- Voice-Based Answer Input
- Practice Mode and Mock Interview Mode
- Interview Reports and Performance Tracking
- Personal Progress History
- Weak Topic Practice
- Admin Dashboard

## 💻 Technologies Used

- JavaScript
- Tailwind CSS

## ⚙️ Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
